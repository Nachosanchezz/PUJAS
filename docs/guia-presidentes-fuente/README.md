# Fuente de la guía para presidentes

`guia.html` es el documento (14 páginas de 1080×1920, formato móvil) y `img/` las capturas de la app que usa.
El PDF que se manda por WhatsApp es [`../guia-presidentes.pdf`](../guia-presidentes.pdf).

Para regenerarlo, abre `guia.html` en Chrome → Imprimir → Guardar como PDF, con márgenes "Ninguno" y la opción "Gráficos de fondo" activada.
Las capturas se hicieron en una sala de ejemplo temporal (código `EJEMPL`) con los equipos reales.
